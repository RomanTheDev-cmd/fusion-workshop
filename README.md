# Мастерская Fusion

Локальное приложение для macOS (Apple Silicon), запускается двойным щелчком по `Мастерская Fusion.app`. Интернет для курса не требуется. Справочные ссылки Autodesk открываются во внешнем браузере только по нажатию.

Встроены 16 полностью написанных занятий в четырёх разделах, включая четыре контрольных проекта. Каждое занятие содержит цель, предварительные знания, новые понятия, объяснение выбора способа, инструменты и расположение в интерфейсе, демонстрацию построения, практику, самостоятельную задачу, проверки, ошибки с причинами, два вопроса теста с объяснениями, усложнение, итог и интервальное повторение.

Первые уроки подробно описывают действия. Вторая часть сокращает подсказки. В продвинутой части разбор по умолчанию скрыт. Контрольные проекты предлагают две подсказки, частичное и полное рекомендуемое решение. Результаты физической печати не выдуманы: уроки содержат протоколы испытаний и различают проверку геометрии, кинематики и прочности.

Практические проекты: бирка, кабельный мостик, монтажная планка, держатель кабеля, лоток, пробник посадок, кронштейн, корпус датчика, корпус с крышкой, петля, защёлка, сервисная коробка, направляющая, регулируемый узел, кривошипно-ползунный механизм, складная подставка.

Прогресс, ответы и заметки сохраняются атомарно в `~/Library/Application Support/FusionWorkshop/progress.json`. Сохранения остаются при обновлении приложения. Нет регистрации, сервера, аналитики или облачной синхронизации. Приложение не подключается к Fusion и не проверяет модель автоматически. Содержание — авторские учебные проекты; готовые CAD-файлы и видеозаписи не входят в комплект. Текстовые демонстрации требуют выполнения в Fusion. Учебные нагрузки не являются подтверждёнными допустимыми нагрузками изделий.

## Разработка

- `Sources/App.swift`: окно AppKit, WKWebView с локальными ресурсами и сохранение данных.
- `Resources/course.js`: содержание курса.
- `Resources/app.js`, `style.css`, `index.html`: учебный интерфейс, тесты и журнал.
- `./build.sh`: сборка `.app` с локальной подписью; нужны инструменты разработчика Apple со Swift.
- `node scripts/check-course.cjs`: проверка полноты курса, всех 16 экранов, контрольных проектов, вопросов, источников и ключевых расчётов. Node нужен только для разработки, не для запуска приложения.

Проверено на этом Mac: сборка и запуск, локальная загрузка всех ресурсов, навигация, раскрытие четырёх уровней помощи, обратная связь теста, запись заметок и отметок, восстановление после перезапуска. Геометрия всех учебных моделей не воспроизводилась в установленном Fusion; физические прототипы не печатались. Требования к сборке и печати проверяются обучающимся по приведённым протоколам.
